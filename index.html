Synchronisation avec GitHub

Toutes tes données sont enregistrées en direct dans ton navigateur (localStorage) ET synchronisables dans ton repo GitHub dans un fichier data/bac_data.json.

Créé un token avec la permission contents: write sur GitHub (Settings > Developer Settings > Personal Access Tokens). Ce token reste stocké uniquement sur ton propre navigateur.
